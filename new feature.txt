## Search behaviour

Search must be case-insensitive and should match:

* Category title
* Category description
* Verse reference
* Verse text
* Verse keywords
* Category ID

Trim the query before searching.

Do not run expensive filtering directly during every render. Use memoised selectors or an appropriate existing project pattern.

## Bookmarks

Allow users to bookmark verses.

Use the project’s existing persistence system. If none exists for local preferences, use `AsyncStorage`.

Store only verse IDs:

```ts
type SavedVerseIds = string[];
```

Create a small reusable hook or service such as:

```ts

```

It should provide:

```ts

isSaved(verseId)
toggleSaved(verseId)
isLoading
```

Do not store duplicate verse objects.
