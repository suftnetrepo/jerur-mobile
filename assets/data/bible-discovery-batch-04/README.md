# Bible Discovery — Story Batch 4

Includes Jesus Calms the Storm, the Good Samaritan, the Prodigal Son, the Cross, and the Resurrection. Each story contains five reading sections, six flashcards, five teaching quiz questions, reflection, prayer, rewards and matching SVG references. Holy Week and Easter metadata is included.

Copy the `stories` directory into `assets/data/bible-discovery/stories/`, or consume `batch-04.json` as one dataset.
