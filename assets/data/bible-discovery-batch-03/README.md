# Bible Discovery — Story Batch 3

Includes Elijah on Mount Carmel, Jonah and the Great Fish, Daniel and the Lions, Esther, and the Birth of Jesus. Each story contains five reading sections, six flashcards, five teaching quiz questions, reflection, prayer, rewards and matching SVG references.

Copy the `stories` directory into `assets/data/bible-discovery/stories/`, or consume `batch-03.json` as one dataset.
