# Bible Discovery — Story Batch 1

Five original, structured Bible-story experiences for Jerur.

## Included

- Creation
- Noah and the Ark
- Abraham
- Joseph
- Moses and the Exodus

Each file contains reading sections, Scripture references, flashcards, lessons, reflection, prayer prompt, five quiz questions, rewards and the matching SVG asset path.

Copy the `stories` directory and JSON support files into `assets/data/bible-discovery/`. Use `batch-01.json` when a single import is more convenient.

The retellings are original summaries based on the cited passages. They do not reproduce a copyrighted modern Bible translation.
