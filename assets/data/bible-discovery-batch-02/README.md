# Bible Discovery — Story Batch 2

Includes Joshua and Jericho, Ruth, Samuel Listens, David and Goliath, and Solomon’s Wisdom. Each story contains five reading sections, six flashcards, five teaching quiz questions, reflection, prayer, rewards and matching SVG references.

Copy the `stories` directory into `assets/data/bible-discovery/stories/`, or consume `batch-02.json` as one dataset.
